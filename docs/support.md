# Support
Need help with something to do with Beacon? There are a few ways to do this.

## Email
We have a public email for any sort of enquiries and support. Simply send an email to [hello@beacondev.org](mailto:hello@beacondev.org) and we'll quickly get back to you.
:::note
We are not interested in any sort of external company to make apps, improve SEO, improve our website, etc. We have had a **lot** of emails to do with this, and we simply don't need this.
:::

## GitHub Issues
Is your problem an actual issue with Beacon itself? Create an issue on the [GitHub repository](https://github.com/Beacondev-Team/Beacon) or use the `/issue` command in the bot to report the problem.
